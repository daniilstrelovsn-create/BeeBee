Тип #11. Вычисление количества информации

Теоретическая справка

Бит (binary digit) — минимальная единица измерения информации, которая может принимать одно из двух значений: 0 или 1.

Байт — единица измерения информации, состоящая из 8 бит. Байт является основной единицей обработки информации в компьютерах.

Типовая задача №1

Условие:
Вася решил закодировать персональные данные всех 1347 учеников всей школы. Для каждого ученика был сформирован ID из нескольких полей: номер класса, буква (а,б,в,г,д), пол, день и месяц рождения, номер имени по таблице имен (всего 103), номер фамилии по таблице фамилий (всего 733).
