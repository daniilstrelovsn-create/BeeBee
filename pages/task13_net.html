Расчёт подсетей: создание сети с 30 подсетями

Шаг 1: Определите общее количество необходимых хостов

Это самый важный шаг. Вам нужно понять, сколько устройств (компьютеров, серверов, принтеров и т.д.) будет в каждой подсети. От этого зависит размер маски для каждой подсети.

Пример для 30 подсетей:
Допустим, у нас есть следующие требования:
• 10 подсетей для филиалов: по 50 хостов в каждой
• 10 подсетей для отделов: по 20 хостов в каждой
• 10 подсетей для Wi-Fi сетей: по 5 хостов в каждой
Важно: Количество хостов всегда считается как 2^n - 2, где n — количество нулевых битов в маске. Мы вычитаем 2 (адрес сети и широковещательный адрес), которые нельзя назначить устройствам.

Шаг 2: Выберите частную IP-сеть

Для такой задачи нам нужна достаточно большая сеть. Идеально подходит частная сеть 10.0.0.0/8 или 172.16.0.0/12, но для примера мы возьмем 192.168.0.0/16.

Исходная сеть: 192.168.0.0/16
Маска: 255.255.0.0
Доступные адреса: 65 534 (от 192.168.0.1 до 192.168.255.254)

Этого нам с избытком хватит.

Шаг 3: Проведём субнеттинг с помощью VLSM

Теперь мы будем "нарезать" нашу большую сеть на маленькие, ориентируясь на требования к количеству хостов. Мы начнем с самых больших подсетей.

Группа A: Подсети по 50 хостов (нужно 10 штук)
Определим размер блока: 50 хостов + 2 (служебных) = 52
Ближайшая степень двойки: 64 (2^6). Значит, для хостов нам нужно 6 бит
Определим маску: 32 - 6 = 26 бит. Маска: /26 (255.255.255.192)
Размер блока: 2^6 = 64 адреса в каждой подсети

Шаг 5: Практическая реализация

  • На маршрутизаторе: Вам нужно настроить интерфейсы (или виртуальные интерфейсы, SVIs) для каждой из этих подсетей, если маршрутизатор является их шлюзом по умолчанию.
  • На коммутаторах (L3): Если у вас есть управляемые коммутаторы, вы можете создать VLAN для каждой подсети и назначить им соответствующий IP-адрес (шлюз).
  • Настройка DHCP (опционально): Настройте DHCP-сервер для раздачи IP-адресов в нужном диапазоне для каждой подсети, исключая из выдачи адрес шлюза.
  • Межсетевая маршрутизация: Убедитесь, что маршрутизатор знает, как передавать трафик между этими подсетями (обычно это происходит автоматически для непосредственно подключенных сетей). Если у вас несколько маршрутизаторов, нужно настроить статические маршруты или динамический протокол маршрутизации (например, OSPF).
